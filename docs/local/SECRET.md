# Secrets

Local environment files come from Azure. Git does not store them.

[Setup](./SETUP.md) covers the rest of local setup.

These files stay on your machine:

- `.env`
- `.env.shared`
- `.env.ci`
- `.env.ci-app`
- `.env.staging`
- `.env.production`
- `.env.production-ro`
- `.env.migrator`
- `infra/.env.production`
- `internal/.env.ci`
- `internal/standup-bot/.env.production`
